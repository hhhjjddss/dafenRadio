## ✨ 功能特性

###   液态玻璃界面

采用液态玻璃设计语言，光影随封面流动，视觉沉浸。

###   探索画布

- 格阵 / 行云 / 左倾 / 右倾 四种排布，可随时切换
- 格阵支持圆形 / 方形封面，封面尺寸、间距与阴影随排布适配
- 拖拽探索、锁定排布、行云左右交替流动，45° 斜列同样支持无限拖动
- 悬停查看歌单信息，点击进入歌单详情

###   双平台音乐库
- 网易云音乐、汽水音乐扫码登录，登录状态自动恢复
- 平台切换后歌单、收藏、推荐各自独立，互不串数据
- 网易云「我喜欢的音乐」红心同步；汽水收藏保存在本机
- 网易云单曲搜索、汽水歌单搜索统一收进居中搜索浮层
- 强调色随平台切换（网易云红 / 汽水绿），封面主色用于动态氛围

###   心动模式与推荐播放
- 网易云心动模式（种子歌曲 + 红心歌单），失败时自动退回私人 FM
- 汽水官方推荐流，两个平台的推荐队列均为 50 首
- 非 VIP / SVIP 账号的推荐队列最多保留 10 首 VIP，避免整队都是只能试听的歌
- 启动时自动播放推荐，可在设置中关闭

###   逐字歌词
- 网易云逐字歌词按人声进度染色；汽水歌词按行高亮
- 歌词页封面固定，仅歌词列表滚动
- 支持翻译、全屏歌词与减少动态效果偏好

###   播放与托盘
- 应用内音频播放、播放模式、音量与 VIP 试听时长提示
- 播放队列面板、黑胶迷你播放器、全屏模式
- 托盘常驻：左键弹出玻璃小面板（封面、歌名/歌手、上一首/播放暂停/下一首）
- 右键菜单：显示主窗口 / 退出 DaFen Radio
- 关闭主窗口收进托盘，音乐继续播放
- 网易云听歌自动打卡：单曲实际播放满 30 秒计入最近播放、听歌排行与听歌时长/等级成长（汽水暂未开放上报）

###   其他
- 首次安装引导，快速完成平台连接与基础操作
- 设置：动态封面配色、启动自动播放推荐、窗口置顶、数据目录、清理缓存
- 快捷键与减少动态效果适配

##   下载安装

### 方式一：下载安装包（推荐）

**[👉 点击前往 Releases 页面下载最新版本](https://github.com/hhhjjddss/dafenRadio/releases)**

### 方式二：自行构建

```bash
# 克隆项目
git clone https://github.com/hhhjjddss/dafenRadio.git
cd dafenRadio

# 安装依赖
npm install

# 启动开发版
npm run dev

# 打包成 exe 安装程序
npm run build:win
```

**环境要求**：Node.js 18+

## 首次使用

1. 启动后按引导，或点击右上角的平台入口
2. 选择网易云音乐 / 汽水音乐，使用对应 App 扫码确认
3. 登录后自动同步收藏、歌单与推荐内容
4. 需要切换平台时，从平台下拉菜单选择即可，各平台登录状态会分别保留

登录凭据使用系统安全存储加密保存在本机，不会发送给渲染进程。

---

##   托盘与快捷键

- 托盘左键：播放控制小面板
- 托盘右键：显示主窗口 / 退出
- 主窗口关闭按钮：收进托盘（真正退出请使用托盘右键菜单）

| 按键 | 功能 |
|:---:|:---:|
| `空格` | 播放 / 暂停 |
| `/` | 打开搜索 |
| `ESC` | 逐层关闭浮层 / 退出全屏 |

---

##   数据说明

- 收藏、登录状态与缓存统一保存在用户数据目录（`%APPDATA%\DaFen Radio\data`），可在设置中打开查看
- 网易云、汽水音乐的搜索、登录与播放地址由第三方接口提供
- 清理缓存只删除封面与网络请求的临时文件（设置里会显示可清理的大小），不影响收藏
